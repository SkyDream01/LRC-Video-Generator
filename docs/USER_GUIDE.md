# 用户指南

本指南覆盖从素材准备到导出 MP4 的完整流程。第一次使用时，建议先运行演示命令确认 Python 依赖和 FFmpeg 都可用。

## 安装与启动

### 安装依赖

需要 Python 3.10 或更高版本：

```bash
python -m pip install -r requirements.txt
```

启动方式：

```bash
python main.py gui
```

Windows 可双击项目根目录的 `start.bat`。脚本只负责找到 Python 并启动 GUI，不会自动安装依赖或下载 FFmpeg。

### 配置 FFmpeg

导出需要 `ffmpeg`。把 `ffmpeg.exe` 放在 `ffmpeg/ffmpeg.exe`，或者把 FFmpeg 的 `bin` 目录加入 `PATH`。建议同时提供 `ffprobe.exe`，这样音频时长可以优先从媒体容器读取；没有 `ffprobe` 时程序会尝试使用 mutagen。

检查安装：

```bash
ffmpeg -version
ffprobe -version
```

FFmpeg 二进制不在仓库中。没有它时可以打开 GUI 和工程，但导出按钮不可用；某些 Qt 无法解码的音频也不能走 FFmpeg PCM 回退。

## 准备素材

| 素材 | 是否必需 | 格式 | 说明 |
| --- | --- | --- | --- |
| 音频 | 导出必需 | `.mp3`、`.wav`、`.flac`、`.m4a` | 用于音轨和时长探测 |
| LRC | GUI 渲染/导出必需 | `.lrc` | 没有有效时间行时不会生成歌词图层 |
| 封面 | 可选 | `.jpg`、`.jpeg`、`.png`、`.webp` | 静态封面、唱片圆标和自动取色使用 |
| 背景 | 可选 | `.jpg`、`.jpeg`、`.png`、`.webp` | 没有背景图时通常使用封面作为模糊背景 |

建议把 `.kproj`、音频、图片和 LRC 放在同一目录。保存工程时，程序会尝试把媒体路径写成相对于工程目录的路径，移动整组文件时更容易保持可用。

## GUI 工作流

### 1. 加载素材

在左侧“素材”面板中选择音频、封面、LRC 和可选背景。选择后会触发后台资源准备；右侧预览会在准备完成后更新。

也可以点“载入演示工程”。它会在 `output/gui_demo/` 生成确定性的 WAV、封面、LRC 和 `.kproj`，然后加载到 GUI。

导出和播放的就绪条件不同：GUI 需要有效会话、音频和 LRC；封面与背景都可以为空。素材路径存在但内容无法读取时，请重新选择文件并查看状态栏错误。

### 2. 调整参数

参数面板包含四个页签：

- 歌词样式：主歌词/译文的字体、字号、颜色、描边颜色和宽度。
- 动画：分别选择背景、歌词、封面动画与动态滤镜。数值控件由动画 schema 自动生成。
- 色彩：自动从封面提取主色/辅色，或关闭自动取色后手动指定；同时可查看本次准备实际使用的颜色。
- 输出：30/60 fps、编码器、视频码率、音频码率，以及是否叠加“标题 − 艺术家”。

自动取色开启时，程序使用固定种子的 K-Means 从封面提取颜色，并在歌词区域采样背景来选择高对比度文字色。若已手动改过歌词主色或描边色，自动模式不会覆盖对应的手动值。

### 3. 预览和定位

时间轴显示歌词行刻度和当前时间。拖动播放头时，画面会立即跟随，松开后再同步音频引擎；播放时主时钟使用单调时钟，并约每 500 ms 使用媒体 PTS 纠漂。

需要检查最终像素时，选择“设置 → 精确预览当前帧”（`F5`）。它会在后台尺寸为 1920×1080 的 `QImage` 上合成当前帧，随后缩放显示，绘制路径与导出相同。

### 4. 保存和导出

- `Ctrl+S` 保存当前工程；首次保存会选择 `.kproj` 路径。
- `Ctrl+O` 打开已有 `.kproj`。
- `Ctrl+E` 选择输出 MP4 并开始后台导出。
- 导出进行中按钮变为“取消导出”；取消不会留下目标路径的半成品。

导出开始前，程序会决定编码器。`auto` 依次尝试 NVIDIA NVENC、AMD AMF、Intel QSV，最后使用 `libx264`。硬件尝试失败时会完整重跑一次软件编码。

## 动画参考

### 动态滤镜

在“动画 → 动态滤镜”选择“柔光流动”或“漂浮光斑”。默认关闭，也可把强度设为 0。
柔光可调强度、周期和光晕大小；光斑还可调数量与随机种子。周期越长，运动越慢。
两种滤镜均使用色彩页中的主色与辅色，叠在背景上，保持封面和歌词清晰；参数随工程保存。
固定随机种子可让拖动时间轴、重复预览和导出时的光斑位置一致。

纵向和圆弧滚动可选择 `smooth` 缓动，使运动起止更柔和；`cubic` 保留原有效果，
`linear` 为匀速。换行时长可调，短句自动缩短过渡以避免跨行跳动。

动画选项按分类排列，分类标题用于导航，不能选作效果。选中效果后，面板会显示行为说明和可调参数；下拉选项也提供悬停说明。新的中文名称兼容已有工程，加载后会显示对应的新名称。

### 背景

| 分类 | 类型 | 效果 | 参数 |
| --- | --- | --- | --- |
| 图片背景 | 静态模糊 | 图片填满画面并模糊，保持静止 | 无 |
| 图片背景 | 呼吸缩放 | 模糊图片缓慢推近、拉远 | 周期：2–60 秒；缩放幅度：0–0.3 |
| 图片背景 | 纵向漂移 | 模糊图片整体上下周期漂移 | 漂移速度：0.05–5.0；漂移幅度：0–1 |
| 生成背景 | 渐变流动 | 用主色、辅色生成水平流动的渐变波纹 | 流动速度：0.05–5.0；波纹强度：0–1 |
| 生成背景 | 午夜雾光 | 固定深蓝配色的静态雾光 | 无 |

图片背景优先使用独立背景图，未设置时使用封面；没有可用图片时使用深色基础色。生成背景无需图片输入，其中午夜雾光不受主色、辅色影响。

### 歌词

| 分类 | 类型 | 效果 | 参数 |
| --- | --- | --- | --- |
| 单行切换 | 淡入淡出 | 当前歌词与译文居中显示，行首、行尾渐变 | 过渡时长：0–2000 ms |
| 单行切换 | 上下滑动 | 当前歌词与译文从下方滑入、向上滑出 | 过渡时长：0–2000 ms；滑动距离：0–160 px |
| 单行切换 | 横向显现 | 每行主歌词与译文从左向右显现 | 显现时长：0–3000 ms |
| 单行切换 | 立体翻转 | 当前歌词与译文整体翻入、翻出 | 过渡时长：0–2000 ms；翻转角度：0–80 度 |
| 多行滚动 | 纵向滚动 | 多行纵向排列，当前行居中高亮 | 可见行数：1–11；缓动：`linear` 或 `cubic` |
| 多行滚动 | 圆弧滚动 | 多行沿封面外侧圆弧滚动，当前行放大并高亮 | 可见行数：3–9；圆弧间隔：12–24 度；换行时长：100–1500 ms |

单行切换以一条歌词及其译文为单位，文本仍可自动换行。横向显现按行触发；Enhanced LRC 的逐字高亮会自动叠加到所有歌词动画。

超出歌词区域的文本会先尝试缩小字号，再最多换成两行，仍放不下时以省略号截断。歌词位图只缓存文字的紧 bbox，不缓存整幅画布。

### 封面

| 分类 | 类型 | 效果 | 参数 |
| --- | --- | --- | --- |
| 方形封面 | 静态倒影 | 封面保持静止，柔和倒影轻微明暗变化 | 无 |
| 方形封面 | 呼吸缩放 | 封面与倒影同步缩小、还原 | 周期：1–30 秒；缩放幅度：0–0.15 |
| 方形封面 | 上下悬浮 | 封面与倒影同步上下浮动 | 周期：1–30 秒；悬浮距离：0–48 px |
| 方形封面 | 立体摇摆 | 封面绕双轴摇摆，隐藏倒影 | 周期：1–30 秒；摇摆角度：0–45 度 |
| 圆形封面 | 黑胶旋转 | 带唱纹、高光的黑胶唱片匀速旋转，带倒影 | 转速：5–78 RPM |
| 圆形封面 | 星环旋转 | 圆形封面静止，外围星环与齿轮装饰旋转 | 星环转速：−3–3 RPM；负值反向旋转 |

黑胶旋转会带动唱片上的封面标签，星环旋转只转动外围装饰。

## LRC 写法

支持标准行级时间标签：

```lrc
[ti:Example Song]
[ar:Example Artist]
[al:Example Album]
[offset:-80]
[00:12.30]第一行歌词
[00:12.30]First lyric line
[00:18.00]第二行歌词
```

解析规则：

- 支持 `[mm:ss]`、`[mm:ss.xx]`、`[mm:ss.xxx]`，同一行可以有多个时间标签。
- 相邻两条歌词的时间差小于 0.05 秒时，第二条会作为第一条的译文；双语文件应让两种语言的行保持顺序。
- `[ti:]`、`[ar:]`、`[al:]` 用于标题、艺术家、专辑；LRC 没有值时才回退到音频标签。
- `[offset:]` 的单位是毫秒，解析后会应用到所有行，时间不会小于 0 秒。
- 没有合法时间戳、正文为空或格式损坏的行会被忽略。

Enhanced LRC 可以被解析，例如：

```lrc
[00:12.30]<00:12.30>First <00:12.80>lyric
```

词级时间会保留在解析结果中，但当前内置歌词动画仍以行级时间为准。

## CLI 使用

### 工程导出

```bash
python main.py export --kproj path/to/project.kproj --output result.mp4
```

### 直接导出

```bash
python main.py export --audio music.flac --lrc lyrics.lrc --cover cover.jpg --output result.mp4
```

直接模式至少要有音频和 LRC。背景可通过 `--background` 指定。`--kproj` 和直接素材参数是两种输入模式，选择一种即可。

常用选项：

```text
--fps 30|60             覆盖帧率
--encoder NAME          覆盖编码器；默认 auto
--duration SECONDS      覆盖时长
--frames N              限制帧数，调试用
--output PATH           输出路径
```

`python main.py demo` 还支持 `--dir` 指定演示工作目录。省略 `--output` 时，普通导出按音频文件名生成 MP4，演示导出写入演示目录的 `demo.mp4`。

## 输出与时长

默认输出：1920×1080、60 fps、H.264 High Profile、`yuv420p`、BT.709/tv、AAC-LC 320 kbps、48 kHz 立体声、MP4 `+faststart`。

帧数按 `round(duration × fps)` 计算。时长优先级为：`--duration` → `ffprobe` → mutagen → 无法读取音频时用最后一条歌词加 5 秒估算。正式导出仍要求音频文件可被 FFmpeg 读取。
