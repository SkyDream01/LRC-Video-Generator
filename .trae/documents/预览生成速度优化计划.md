# 预览生成速度优化计划

## 问题分析

当前预览生成流程存在以下性能瓶颈：

### 1. 分辨率不够低
- 当前预览缩放到 50%，仍可进一步降低

### 2. FFmpeg 启动开销
- 每次预览都启动新的 FFmpeg 进程
- 每次都创建临时滤镜文件

### 3. 缺乏缓存机制
- 相同参数的预览无法复用

---

## 优化方案

### 优化一：大幅降低预览分辨率
**目标**：将预览分辨率从 50% 降低到 25%（约 480x270）

**修改位置**：`video_processor.py` 第86-92行

```python
# 当前
scale_factor = 0.5

# 优化后
scale_factor = 0.25  # 1080p -> 270p，速度提升约 16 倍
```

**预期效果**：像素数量减少 75%，处理速度提升 4-16 倍

---

### 优化二：预览缓存机制
**目标**：缓存已生成的预览，避免重复计算

**修改位置**：`main_ui.py`

**实现方案**：
1. 添加 `_preview_cache` 字典，存储 `{参数哈希: QPixmap}`
2. 生成预览前检查缓存
3. 参数变化时清除缓存

```python
def _get_preview_cache_key(self) -> str:
    """生成预览缓存键"""
    params = self._gather_parameters()
    if not params: return None
    key_data = (
        params.cover_path, params.background_path,
        params.preview_time, params.background_anim,
        params.text_anim, params.cover_anim,
        params.color_primary, params.color_secondary,
        # ... 其他关键参数
    )
    return hashlib.md5(str(key_data).encode()).hexdigest()
```

---

### 优化三：FFmpeg 参数优化
**目标**：添加加速参数

**修改位置**：`video_processor.py` 第315-321行

**新增参数**：
```python
command = [
    *command_base,
    '-threads', '1',           # 单线程足够处理1帧
    '-noautorotate',           # 跳过自动旋转检测
    '-fflags', 'nobuffer',     # 减少缓冲
    '-flags', 'low_delay',     # 低延迟模式
    *command_filters,
    '-map', '[v]',
    '-frames:v', '1',
    str(params.output_image_path)
]
```

---

### 优化四：防抖机制
**目标**：用户拖动滑块时不立即生成，等待停止后再生成

**修改位置**：`main_ui.py`

**实现方案**：
1. 使用 `QTimer` 实现延迟生成
2. 滑块拖动时只更新时间显示
3. 停止拖动 300ms 后自动生成预览

---

## 实施优先级

| 优先级 | 优化项 | 预期提升 | 实施难度 |
|--------|--------|----------|----------|
| P0 | 降低预览分辨率到 25% | 4-16x | 低 |
| P1 | FFmpeg 参数优化 | 1.2-1.5x | 低 |
| P1 | 预览缓存机制 | 避免重复计算 | 中 |
| P2 | 防抖机制 | 减少无效计算 | 低 |

---

## 预期效果

综合优化后，预览生成时间预计从 **3-5秒** 降低到 **1-2秒**。
